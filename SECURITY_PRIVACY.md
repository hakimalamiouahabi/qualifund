# Sécurité & confidentialité

- Aucune donnée projet n’est envoyée au moteur de collecte.
- Les informations saisies restent dans `localStorage` du navigateur.
- Aucun token GitHub/API n’est embarqué dans le front-end.
- Les connecteurs travaillent uniquement sur des sources publiques.
- Les documents liés restent hébergés par leurs sources officielles ; Qualifund conserve les URL et empreintes, pas les fichiers sensibles.
