# Activation finale v12.2.0

## Poste professionnel sans droits administrateur

Utiliser directement `LEYTON-RADAR-v12.2.0-AUTONOME-LIVE.html`.

Aucune installation n'est nécessaire. Pour rafraîchir la base :

- utiliser `Mettre à jour la cartographie` ;
- ou télécharger le stock officiel Aides Entreprises dans le navigateur puis sélectionner `Importer stock officiel`.

## Collecte exhaustive planifiée

Le pipeline hébergé reste inclus dans la release. Il est indépendant des droits administrateur du poste utilisateur : une fois déployé sur un runner externe, il exécute les 111 sources d'ingestion, les 34 contrôles, la QA, la remédiation et le déploiement quotidien.
