# Politique de vérification des fiches AAP — QUALIFUND v9.2

Chaque AAP / dispositif doit être matérialisé par une fiche canonique unique.

## Champs obligatoires
1. Objectif
2. Thématiques visées
3. Bénéficiaires
4. Type d'aide : SUBVENTION / AVANCE_REMBOURSABLE / PRET_TAUX_ZERO
5. Répartition SUB/AR/PTZ, si applicable
6. Assiette minimale et maximale, si documentée
7. Montant d'aide minimal et maximal
8. Taux d'aide par taille d'entreprise, si documenté
9. Portée : national / régional / territorial
10. Région
11. Financeur
12. Opérateur / guichet
13. Dépenses éligibles
14. Dépenses exclues, si documentées
15. Projets attendus
16. Pré-requis
17. Critères de sélection
18. Points de vigilance
19. Date d'ouverture
20. Date de clôture finale
21. Dates de relèves
22. Prochaine relève accessible
23. Modalités de versement, si documentées
24. Modalités de remboursement AR / prêt à taux zéro, si documentées
25. Cahier des charges / règlement
26. Annexes utiles
27. Source officielle
28. Date de dernière vérification
29. Niveau de preuve par champ

## Hiérarchie de preuve
A — cahier des charges / règlement / convention / annexe financière officielle
B — page officielle de l'opérateur / financeur
C — base publique officielle transversale
D — agrégateur secondaire, uniquement pour découverte/contrôle

Aucune valeur n'est extrapolée. Toute donnée absente est stockée :
`NON DOCUMENTÉ — À VÉRIFIER`.

En cas de contradiction : document officiel le plus récent > document plus ancien ; CdC/règlement > page catalogue ; page opérateur actuelle > communiqué historique.

## Règle temporelle
Une opportunité est recommandable si sa prochaine échéance est >= J+1 ou si son caractère permanent est officiellement confirmé.
