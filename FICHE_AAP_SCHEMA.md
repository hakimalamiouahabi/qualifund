# Fiche standard Qualifund — consultant senior

| Bloc | Champs |
|---|---|
| Identité | intitulé, financeur, opérateur, programme, édition, identifiant |
| Objectif | finalité officielle du dispositif |
| Bénéficiaires | texte officiel + STARTUP/PME/ETI/GE |
| Thématiques | R&D/innovation, investissement, numérique, écologique + sous-thèmes |
| Portée | national/régional + territoire |
| Aide | SUBVENTION / AVANCE REMBOURSABLE / PRÊT À TAUX ZÉRO |
| Taux | min/max + taux par taille si publié |
| Montants | min/max/plafond + montants par taille si publiés |
| Projets attendus | opérations, maturité, consortium, TRL si publiés |
| Dépenses | dépenses éligibles + exclues |
| Calendrier | ouverture, relèves, prochaine relève, clôture finale, permanence |
| Pré-requis | taille, secteur, territoire, seuils, effet incitatif, consortium, maturité |
| Sélection | critères et pondérations lorsqu’elles sont publiées |
| Points d’attention | ambiguïtés, risques, données à sécuriser |
| Documents | CdC/règlement direct + empreinte documentaire si PDF analysé |
| Preuves | champ, niveau A/B/C/D, URL, date de contrôle, extrait |
